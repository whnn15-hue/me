# 증빙 연결과 활동 경력 정리

## 요청과 보존 범위

2026-11-13 요청은 기존 학교폭력예방 컨설팅단을 유지하면서 2022 어울림 컨설팅 지원단을 별도로 관리하고, 봉덕초 소속으로 확인한 서포터즈 증빙을 정확히 연결하는 작업이다. 추가로 받은 2023~2025 지원단 자료도 같은 묶음에 포함한다. 원본과 기존 이력은 삭제하지 않는다. 작업 전 백업은 `backup/before-eoullim-career-20261113` (`0e20523`)이다.

## 화면과 저장

- 이력 목록 오른쪽 버튼으로 `증빙 확보 어려움`을 표시하거나 해제한다. 해당 기록은 홈의 증빙 보완 대상에서 제외되고 전용 필터에서 찾을 수 있다.
- 실제 문서가 연결되면 `증빙 있음`이 우선한다. 단축 버튼은 증빙 상태만 저장하여 다른 창에서 수정한 메모와 연결을 보존한다.
- 기존 `unneeded`와 구분하는 선택값 `unavailable`을 추가했다. 이전 데이터는 변환 없이 읽으며, 브라우저와 서버 저장, 백업 복원에서 새 값을 유지한다.
- 몽당분필 모임 활동과 파견 업무를 이력의 `활동 경력`으로 묶는다. 실제 영상 제작과 강의 이력은 해당 분류에 남는다. 이전 저장 분류를 덮어쓰지 않으며 기존 파견 필터도 유지한다.

## 원본 검토와 연결

새로 받은 22개 중 19개를 증빙으로 선정했다. 빈 컨설팅 결과보고서, 빈 연구회 결과보고서 및 정산서, 중복 연구비 지급표는 이번 등록에서 제외한다. 이 파일들의 원본은 비공개 작업 폴더에 보존한다. 기존 증빙과 같은 두 파일은 SHA-256 기준으로 재사용한다.

앞서 받은 2022년 문서 세 개와 합쳐 원본 22개를 암호화한 가져오기 묶음으로 제공한다. 봉덕초 명단으로 확인한 어울림 컨설팅 지원단은 별도 경력 하나를 만들고, 서포터즈 문서 두 개는 기존 어울림 서포터즈단에 연결한다. 2023년과 2024년 학교폭력 예방교육 컨설팅단은 각 연도 이력에 남긴다. 에듀테크 활용 교육, 함께학교, 퀴즈나비, 미래형 수업 나눔, 온라인학습 연구회와 미디어교육지원단도 기존 이력에 연결한다.

명단에 명시된 위촉기간은 보완하되, 단일 협의회 날짜나 보고서 제출 기한으로 전체 활동기간을 줄이지 않는다. 참석 안내를 참석 완료나 수료 확인서로 바꾸지 않는다. 파일 확장자만 HWP였던 함께학교 운영계획은 실제 HWPX 구조에 맞춰 이름을 고치고 바이트는 그대로 보존한다.

## 자동 저장과 복구

정확한 패키지 해시에만 신규 경력, 상세 보완, 기존 연결 정정 권한을 각각 부여한다. 정정은 검증된 동일 원본의 지정된 연결 하나만 분리하며, 기존 경력의 이름과 연도가 일치할 때만 적용한다. 다른 원본과 연결은 유지한다. 기존 3개 파일 패키지의 자동 승인은 해제하여 옛 링크가 잘못된 연결을 다시 만들지 않도록 했다.

원본 추가, 연결 정정과 이력 보완은 최신 스냅샷을 기준으로 한 번에 활성화한다. 중복 실행은 원본을 재업로드하지 않으며, 승인된 작업이 네트워크 문제로 실패하면 선택이 변경되지 않은 경우에만 검토된 연결을 다시 시도할 수 있다. 사용자의 이름, 기간, 메모 수정은 보존한다.

원본 ZIP과 복호화 코드는 `.cloud-local`에만 둔다. Git에는 암호문과 승인 해시만 넣으며 코드는 브라우저 URL fragment로 전달한다. 패키지 준비 또는 소스 푸시는 실제 계정 저장 완료가 아니다. 실제 저장에는 소유자가 로그인하고 저장소가 연결된 앱에서 해당 링크를 여는 과정이 필요하다.

## 검증과 되돌리기

합성 데이터로 상태 표시, 재접속, 해제, 저장 실패, 동시 메모 수정, 새 증빙 우선순위, 분류 및 백업 복원을 확인한다. 증빙 가져오기는 외부 요청을 차단한 검증 환경에서 첫 실행, 이전 패키지에서 전환, 재실행과 원본 보존을 검사한다. 운영 Firebase와 Drive/OneDrive는 검사에 사용하지 않는다.

코드는 배포 merge 커밋을 `git revert -m 1 <merge-commit>`으로 되돌리거나 백업 브랜치를 별도 checkout하여 확인할 수 있다. 코드 되돌리기는 이미 가져온 이력을 삭제하지 않는다. 새 증빙 상태 표시는 앱에서 같은 버튼으로 해제할 수 있고 문서 연결은 이력 상세에서 조정할 수 있다.
