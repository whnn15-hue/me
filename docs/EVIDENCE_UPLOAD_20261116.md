# 새 경력 2건과 PDF 증빙 (2026-11-16)

두 공문에 확인되는 새 경력을 등록하고 각 PDF 원본을 해당 경력에 연결한다. 학생영상제 운영위원 위촉은 `위원회·지원단`, 수학탐험대 활용 숏폼 공모전 입상은 `공모전 수상`으로 분류한다.

운영위원 기록의 2026-09-18~21은 공문에 안내된 협의 일정이며, 전체 위촉 기간이나 협의 참석 완료로 단정하지 않는다. 공문 발급일은 9월 16일이다. 공모전 입상 기록의 날짜는 문서에 확인되는 2026년까지만 입력한다. 수상 등급과 정확한 수상일은 추정하지 않으며 11월 26일은 예정된 시상식으로만 설명한다.

PDF 원본 바이트, 파일명, 문서 ID와 SHA-256을 보존한다. 기존에 원본만 저장한 계정에서는 파일을 재업로드하지 않고 새 경력 2건을 만들고 연결한다. 반복 가져오기는 기존 경력과 원본을 재사용하며 사용자 메모를 덮어쓰지 않는다. 같은 제목·기관·호환되는 날짜의 경력이 이미 하나 존재하면 재사용하고, 여러 건이 일치하거나 기존 ID의 정체성이 달라졌으면 자동 저장을 중단한다.

정확한 새 ZIP 해시 `d0e2193660b98336e9e8fc60cf13da858c184cc0b4e3c586f88cd6dc3e213e6c`만 새 경력 생성 승인 목록에 등록한다. 기존 원본 전용 묶음의 자동 승인은 해제한다. 경력 수정이나 기존 증빙 연결 제거 권한은 부여하지 않는다.

원본, 검토 목록, 가져오기 ZIP과 비공개 링크는 `.cloud-local/pending-upload-20261116/`에만 보관한다. 공개 자산 `public/imports/5678fa36e7a635c5.bin`은 AES-256-GCM 암호문이다. 기존 전용 링크를 계속 사용할 수 있도록 자산 주소와 키를 유지하되 암호화 IV는 새로 생성했다. 복호화 키는 Git·로그·공개 번들에 포함하지 않는다.

실제 저장은 본인 로그인과 OneDrive 연결이 완료된 앱에서 전용 링크를 열었을 때 수행된다. 기존 열기 파일을 다시 열면 새 앱 페이지와 수정된 묶음을 받는다. 이미 열려 있는 설정 화면에서 같은 코드만 다시 사용하는 대신 완전한 페이지 이동을 해야 한다. 평소 사이트 주소 접속이나 코드 배포만으로 실제 계정 저장이 완료되는 것은 아니다.
