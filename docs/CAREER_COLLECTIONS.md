# 이력 분류와 기관별 보기

상위 메뉴는 이력, 수업, 강의 자료, 대학원입니다. 공문 보관함, 이력서와 증빙, 백업 설정은 보관 도구로 유지합니다.

이력 안에서 전체, 강의와 연수, 위원회와 지원단, 연구대회, 표창, 파견, 집필, 콘텐츠 제작, 자격증, 기타를 선택합니다. 근무 탭은 없으며, 파견이 아닌 과거 근무 기록은 전체와 기타에 남습니다.

## 분류

- 한 기록은 한 분류에만 표시됩니다. 전체에서는 모든 기록을 한 번씩 보여 줍니다.
- KERIS 내부 업무에 해당하는 운영계획, 사업계획과 파견 기록은 파견에 모입니다. KERIS가 초빙한 외부 강의나 제안서 평가 활동까지 기관명만으로 파견 처리하지 않습니다.
- 집필은 도서 저술과 학교폭력 자료집 집필입니다. 영상, 교육자료와 홍보자료 제작은 콘텐츠 제작으로 표시합니다. 검토위원 활동은 위원회와 지원단에 남습니다.
- 기존 연구와 수상 기록에서 표창을 분리합니다. 연구대회에는 기존 등급, 예선과 본선 정보가 계속 표시되며, 표창에는 대회 등급 미기재 안내를 표시하지 않습니다.
- 강의와 연수는 기관명을 제목 위에 표시하며 기본적으로 기관별로 묶습니다. 기관, 연도, 증빙 여부로 필터링하거나 연도별 보기로 전환할 수 있습니다. 미입력 기관도 별도로 검색하고 수정할 수 있습니다.

기존 기록의 ID, 원래 분류, 날짜, 역할, 증빙 파일과 자료 연결은 다시 쓰지 않습니다. 표시할 때 공통 분류 규칙을 적용하므로 재가져오기나 별도의 데이터 마이그레이션이 필요 없습니다. 새 분류인 연구대회와 표창을 저장할 수 있도록 양쪽 저장 검증기를 확장했으며 과거 분류도 계속 읽고 복원합니다. 통합 검색과 이력서 선택, 이력서 CSV도 같은 표시 분류를 사용합니다. 전체 데이터 JSON과 ZIP 백업은 원본 값을 보존합니다.

## 화면

Paperlogy 제목과 기존 녹색 톤을 유지했습니다. 중복된 사이드바 분류를 제거하고 이력 화면의 분류로 통합했습니다. 작은 통계, 간결한 파일 끌어 놓기 영역, 기관별 목록과 모바일 가로 분류 메뉴로 기록에 빠르게 접근합니다. 상위 네 메뉴는 휴대폰에서도 바로 전환할 수 있습니다.

## 바뀐 파일

- `src/App.tsx`, `src/career-portfolio.css`, `src/main.tsx`: 메뉴 계층, 기관 검색과 묶어보기, 반응형 화면.
- `shared/career-organization.mjs`, 대응 선언 파일: 중복 없는 분류와 기관 표시 규칙.
- `src/CareerEditor.tsx`, `src/types.ts`, `server/store.mjs`, `server/extract.mjs`: 분리된 분류 선택, 검증과 업로드 초안.
- `src/ResumeBuilder.tsx`, `src/workspace/WorkspaceSearch.tsx`: 분류를 이력서와 검색에 일관되게 적용.
- `test/streamlined-data.test.mjs`, `test/streamlined-e2e.spec.ts`, `test/extract.test.mjs`, `test/e2e.spec.ts`: 분류 보존, 중복 방지, 기관 필터, 기존 흐름과 모바일 검증.
