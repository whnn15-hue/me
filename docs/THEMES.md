# 중성 색상과 화면 모드

기록 달력을 제거하고 성장 차트의 너비를 넓혔습니다. 달력에서 보여 주던 이력 날짜, 수업 날짜, 과제 마감일은 원래 항목에 그대로 남습니다.

## 색상 기준

`src/theme.css`에서 모든 화면의 공통 색상을 관리합니다.

| 역할 | 밝은 화면 | 어두운 화면 |
| --- | --- | --- |
| 배경 | `#f3f3f3` | `#141414` |
| 카드, 팝업 | `#ffffff` | `#202020` |
| 기본 글씨 | `#242424` | `#ededed` |
| 보조 글씨 | `#666666` | `#b6b6b6` |
| 선택 강조 | 민트 | 밝은 민트 |

기존 CSS의 연두색 배경, 초록빛 글씨, 테두리를 역할별 `--ui-*` 변수로 연결했습니다. 레이아웃 선언과 데이터 처리에는 손대지 않았습니다. 오류, 주의, 연결 완료 등 의미가 있는 상태색은 유지하면서 두 모드에서 읽히는 색을 지정했습니다. 지도와 자료에 쓰는 생성 이미지 파일은 그대로 사용하며, 야간에는 지도 배경의 표시 불투명도를 낮춥니다.

## 화면 위에서 선택

- 상단에 항상 보이는 `라이트 / 다크 / 시스템` 버튼으로 선택합니다. 로그인 전에도 표시합니다.
- 라이트와 다크는 PC 설정과 관계없이 해당 모드로 고정됩니다. 시스템을 선택하면 `prefers-color-scheme`에 따라 실시간으로 바뀝니다. 초기 기본값은 이전 버전과 같은 시스템입니다.
- 시스템은 고정된 밤 시간이나 위치를 추정하지 않습니다. OS가 예약 시간에 다크 모드로 전환하면 앱도 함께 전환됩니다.
- 선택은 이 브라우저의 `localStorage` 키 `introduce-me-theme`에 저장됩니다. 새로고침 및 같은 사이트의 다른 탭에도 반영합니다. 다른 PC로 동기화하는 계정 설정은 아닙니다.
- 브라우저 저장이 차단되어 있어도 현재 페이지의 모드는 바꿀 수 있습니다. 저장된 값이 잘못되면 시스템 모드로 돌아갑니다.
- `src/theme.ts`에서 첫 React 렌더 전에 저장된 설정을 적용하고, `src/ThemeControl.tsx`에서 선택 상태를 표시합니다. 화면 컴포넌트를 다시 만들지 않으므로 작성 중인 입력값이 유지됩니다. 서버 데이터는 바뀌지 않습니다.
- `color-scheme`을 함께 설정해 기본 드롭다운, 스크롤바, 날짜 입력도 같은 테마를 사용합니다.
- 브라우저 상단 색상에 쓰는 `theme-color`도 실제 선택한 모드를 따릅니다.
- 증빙 원본, 업로드한 HTML의 격리 미리보기, 별도로 생성하는 제출용 문서는 원본 표현을 유지합니다.

## 검증과 변경 파일

이번 변경은 데스크톱만 검사합니다. `test/theme-e2e.spec.ts`는 초기 화면, 입력 중 실시간 테마 전환, 네 탭의 입력창, 설정, 통합 검색, 새로고침 후 테마 유지와 데이터 불변을 확인합니다. 기존 이력 CRUD, 공문 업로드, 증빙, HWPX, ZIP 복원과 성장 지도 시나리오도 데스크톱에서 실행합니다.

- 추가: `src/theme.css`, `test/theme-e2e.spec.ts`, 이 문서.
- 수정: `index.html`, `src/main.tsx`, 공통 및 각 화면의 CSS 11개, `src/App.tsx`, `src/growth/GrowthOverview.tsx`, `src/growth/growth-model.ts`, 성장 관련 검사와 Playwright 설정.
- 삭제: `src/growth/RecordCalendar.tsx`와 달력 전용 집계 및 스타일.
- 저장소, Firestore, Drive, JSON 및 ZIP 구조 변경 없음. 데이터 마이그레이션 없음.

검증 결과: 빌드, 성장 집계 검사 3개, 데스크톱 브라우저 시나리오 3개가 통과했습니다. 로컬 이력 65건 및 공문 데이터는 이전 백업과 전체 행 비교에서 동일했습니다. 휴대폰과 태블릿 검사는 이번 작업에 실행하지 않았습니다.
