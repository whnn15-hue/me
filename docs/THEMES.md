# 중성 색상과 자동 야간 모드

기록 달력을 제거하고 성장 차트의 너비를 넓혔습니다. 달력에서 보여 주던 이력 날짜, 수업 날짜, 과제 마감일은 원래 항목에 그대로 남습니다.

## 색상 기준

`src/theme.css`에서 모든 화면의 공통 색상을 관리합니다.

| 역할 | 밝은 화면 | 어두운 화면 |
| --- | --- | --- |
| 배경 | `#f3f3f3` | `#141414` |
| 카드, 팝업 | `#ffffff` | `#202020` |
| 기본 글씨 | `#242424` | `#ededed` |
| 보조 글씨 | `#666666` | `#b6b6b6` |
| 선택 강조 | 민트 | 밝은 민트 |

기존 CSS의 연두색 배경, 초록빛 글씨, 테두리를 역할별 `--ui-*` 변수로 연결했습니다. 레이아웃 선언과 데이터 처리에는 손대지 않았습니다. 오류, 주의, 연결 완료 등 의미가 있는 상태색은 유지하면서 두 모드에서 읽히는 색을 지정했습니다. 지도와 자료에 쓰는 생성 이미지 파일은 그대로 사용하며, 야간에는 지도 배경의 표시 불투명도를 낮춥니다.

## 자동 전환

- `prefers-color-scheme: dark`로 PC와 브라우저의 테마 설정을 따릅니다. 별도의 앱 설정이나 새로고침이 필요 없습니다.
- 고정된 밤 시간이나 위치를 추정하지 않습니다. OS가 예약 시간에 다크 모드로 전환하면 앱도 함께 전환됩니다.
- CSS로만 전환하므로 작성 중인 입력값이나 선택한 기록이 초기화되지 않습니다. 테마 상태를 서버에 저장하지 않습니다.
- `color-scheme`을 함께 설정해 기본 드롭다운, 스크롤바, 날짜 입력도 같은 테마를 사용합니다.
- 증빙 원본, 업로드한 HTML의 격리 미리보기, 별도로 생성하는 제출용 문서는 원본 표현을 유지합니다.
