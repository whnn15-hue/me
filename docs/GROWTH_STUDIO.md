# 성장 대시보드와 탐색 메뉴

기존 이력, 수업, 강의 자료, 대학원에 밝은 중성 배경과 흰색 카드, 민트색 강조, 둥근 전환 버튼을 적용했습니다. 제공받은 네 번째 화면의 여백과 카드 구성, 세 번째 화면의 접이식 탐색 메뉴를 참고했습니다.

## 기능

- 이력 첫 화면의 성장 지도에서 연도를 선택하면 해당 연도의 모든 이력을 확인하고 원래 상세 화면을 열 수 있습니다. 이전 및 다음 버튼으로 다른 연도도 살펴볼 수 있습니다.
- 기록의 흐름은 누적 또는 연도별 막대 차트로 전환할 수 있습니다. 최근 6년, 12년, 전체 기간과 수치 표를 지원합니다.
- 활동 분야 도넛 차트의 범례를 누르면 기존 이력 분류 필터로 이동합니다.
- 기록 달력에는 이력 시작일, 수업 시작일, 대학원 과제 마감일을 표시합니다. 항목을 누르면 해당 상세 기록으로 이동합니다.
- 사이드바에서 네 영역의 하위 메뉴를 접거나 펼칩니다. 강의 자료의 과목과 즐겨찾기, 수업의 학급 자료, 대학원의 각 종류로 바로 이동합니다.
- 성장 영역 접기와 사이드바 펼침 상태만 브라우저에 저장합니다. 이력 목록 바로가기와 휴대폰용 메뉴를 유지합니다.

## 집계 기준과 데이터 보존

- 지도는 **활동 시작 연도에 따른 탐색 지도**입니다. 실제 장소나 능력 점수를 추정하지 않습니다. 그림의 경로 높이는 장식입니다.
- 시작일이 오늘까지인 기록만 지도와 성장 차트에 포함하고, 여러 해에 걸친 이력도 시작 연도에 한 번 집계합니다. 기록이 없는 연도도 차트에 남습니다. 누적값은 선택한 표시 기간 이전 기록도 포함합니다.
- 날짜 미입력 기록과 예정된 기록은 지도 및 성장 차트에서 제외하고 건수를 표시합니다. 오늘은 한국 시간 기준입니다.
- 분야별 분포는 예정, 날짜 미입력 기록을 포함한 전체 이력 기준이며 기존 분류 로직을 그대로 사용합니다.
- 달력은 유효한 날짜의 일자까지 입력된 기록만 사용합니다. 연도 또는 월만 있는 기록에 임의 날짜를 붙이지 않습니다.
- 기존 데이터 스키마, Firestore, SQLite, 저장 및 백업 API는 변경하지 않았습니다. 데이터 마이그레이션은 필요 없습니다. 화면 탐색은 저장 요청을 발생시키지 않습니다.

## 생성 이미지

OpenAI GPT 이미지 생성으로 이번 작업에 맞게 제작한 추상 그래픽입니다. 개인정보나 원본 공문을 사용하지 않았습니다. 기존 Lucide 조작 아이콘은 유지합니다.

- `public/art/growth-landscape.webp`: 밝은 종이 지형, 민트색 경로, 작은 책과 새싹이 있는 지도 배경. 원본은 `/workspace/generated_images/exec-e453b3ae-671c-4d70-9c35-357d3c59428c.png`에 보존했습니다.
- `public/art/workspace-symbols.webp`: 이력 카드 묶음, 펼친 책, 자료 폴더, 학사모를 동일한 질감으로 만든 투명 배경 2×2 이미지. CSS 배경 위치로 네 메뉴에 사용합니다. 원본은 `/workspace/generated_images/exec-e346a0e5-1e08-4c98-ae27-23e62b1854fd.png`에 보존했습니다.

두 파일은 원본을 WebP로 변환했고 전체 전송량은 약 228 KiB입니다. 외부 이미지 서비스에 접속하지 않습니다.

## 검증

`npm test` 242개와 `npm run test:e2e` 12개 시나리오가 통과했습니다. `npm run build`, `npm run build:functions`도 통과했습니다. 브라우저 검사는 실제 계정 대신 임시 SQLite 저장소에서 실행합니다. 지도에서 상세 열기, 차트 전환과 수치 표, 달력 이동, 분야 필터, 하위 메뉴 이동과 상태 기억, 390/768/900px 배치를 검사합니다. 기존 이력 CRUD, 공문, HTML 자료, 전체 JSON과 ZIP 백업, 연결과 동시 수정 검사도 유지합니다.

로컬 원본 저장소의 이력 65건과 공문 0건은 작업 전 백업과 전체 행 비교에서 동일했습니다. 실제 Firebase 데이터에는 이 검증용 기록을 저장하지 않습니다.
