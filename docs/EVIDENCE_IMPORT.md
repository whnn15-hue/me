# 검토한 증빙 추가

## 연결 목록 바로 열기

개인 증빙 링크를 열면 로그인 후 준비된 연결 목록을 자동으로 불러옵니다. 링크 형식은 `/#settings?evidence=<증빙 코드>`입니다. 코드는 URL fragment에만 들어가고, 앱이 읽은 뒤 주소에서 지웁니다. 로그인 대기 중에는 메모리에만 유지하며 저장소, 로그나 백업에 기록하지 않습니다. 새로고침으로 사라졌다면 원래 링크를 다시 열면 됩니다. 실제 코드를 소스나 공개 문서에 넣지 않습니다.

채팅에서 소유자가 바로 저장하도록 요청한 검토 완료 묶음은 로그인과 드라이브 연결 후 추가 버튼 없이 저장합니다. `src/free/evidence-approvals.ts`에 등록된 ZIP 전체의 SHA-256과 일치해야 하며 URL 옵션이나 묶음 내부 플래그로 자동 저장을 허용할 수 없습니다. 복호화 키는 이 목록에 넣지 않습니다. 같은 묶음을 코드나 ZIP으로 불러와도 동일하게 동작합니다.

현재 자동 저장은 기존 이력에 증빙을 추가하는 경우만 지원합니다. 이력 ID, 제목과 활동 연도를 대조하고 저장 직전 최신 데이터로 다시 확인합니다. 대상이 삭제되거나 다른 활동으로 바뀌었거나 새 이력 생성이 필요하면 연결 화면으로 전환합니다. 드라이브 연결을 기다리는 동안 취소하거나 연결을 편집하면 자동 저장도 취소됩니다. 실패한 작업은 반복 재시도하지 않습니다.

등록되지 않은 묶음은 연결 목록만 불러옵니다. `증빙 추가하고 연결`을 눌러야 실제 파일과 연결을 저장합니다. 로그인 전이나 격리 미리보기에서는 비공개 증빙을 불러오지 않습니다. 일반 코드 입력과 ZIP 가져오기도 계속 지원합니다.

## 코드 또는 ZIP으로 가져오기

Firebase 무료 구성의 `백업 및 설정 → 정리한 증빙 가져오기`에서 증빙 코드 또는 ZIP을 불러옵니다. 일반 묶음은 원본 목록, 기존 경력 연결, 추가할 새 경력을 확인하고 `증빙 추가하고 연결`을 누르면 현재 연결된 드라이브에 원본을 보관하고 앱에 경력과 연결을 저장합니다. 위에서 설명한 자동 저장 승인 묶음에는 추가 클릭이 필요하지 않습니다.

기존 경력 내용과 작업 공간은 유지합니다. 같은 원본은 SHA-256으로 찾아 재사용하고 같은 ID의 새 경력이 이미 있으면 현재 기록을 우선합니다. 변경할 내용이 없는 재가져오기는 저장 버전도 바꾸지 않습니다. 새 경력을 선택 해제하면 해당 연결도 제외하지만 원본은 공문 보관함에 보관할 수 있습니다.

새 경력 제안은 ZIP의 `evidenceImport.newCareerIds`에 명시된 항목만 허용합니다. 실제 생성에는 별도의 `approvedNewCareerIds` 선택이 필요합니다. 저장된 `verified` 필드는 호환성을 위해 유지하지만 확인 상태 배지, 수동 확인 목록, 이력서의 확인 상태 표시는 사용하지 않습니다. 이전 형식의 증빙 묶음은 경력을 생성하지 않는 기존 동작을 유지합니다. 최종 저장 시 최신 버전을 확인하므로 다른 창에서 바뀐 내용을 덮어쓰지 않습니다.

PDF, HWP, HWPX, XLSX와 ZIP 기반 한셀 CELL 원본을 지원합니다. 형식 검증과 백업에도 같은 확장자 목록을 적용합니다. 한셀 추가는 원본 보관을 지원하는 변경이며 앱의 자동 본문 추출 범위를 확장하지는 않습니다.

배포용 증빙 묶음은 AES-256-GCM으로 암호화합니다. 공개 디렉터리에는 암호문만 두고 원본, 검토 자료와 복호화 코드는 Git에 포함하지 않습니다. 코드를 받은 사용자의 브라우저에서 복호화하며, 코드에 들어 있는 키는 파일 요청에 포함하지 않습니다.

이번 확장은 기존 스키마를 바꾸지 않습니다. 되돌릴 때는 해당 기능 커밋을 `git revert`하여 다시 배포합니다. 작업 직전 기준 커밋은 `9ca42a24047a43f3d0e2a0120a3dc3ebd4525aec`입니다. 코드 되돌리기는 이미 저장된 경력과 원본을 삭제하지 않습니다.

검증에는 임시 데이터와 모의 클라우드를 사용하며 실제 사용자 계정에 쓰지 않습니다. 자동 저장 경로는 로그인 대기, 저장소 연결 대기, 취소, 수동 편집, 실패 후 수동 재시도, 해시 변조, 최신 이력 변경, 중복 재가져오기를 점검합니다. 2026-11-12 업데이트는 웹앱 빌드와 격리 미리보기 빌드 및 데스크톱 브라우저에서 확인했습니다.
