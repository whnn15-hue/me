# 기록실 탐색 개선, 2026-10-21

기존 Firebase, 드라이브, 로컬 저장 형식과 원본 파일은 유지합니다. 데이터 마이그레이션이나 새 라이브러리 추가는 없습니다.

## 달라진 사용 흐름

- 홈에서 통합 검색을 열고, 증빙 보완, 내용 확인, 날짜 입력, 미연결 공문 목록으로 바로 이동합니다. 즐겨찾는 수업과 자료도 홈에서 엽니다.
- 통합 검색은 제목 일치를 먼저 보여 줍니다. 기관, 본문, 태그도 검색하며 여러 단어의 입력 순서는 상관없습니다. Mac에서는 `⌘ K`, Windows에서는 `Ctrl K`로 열고 방향키와 Enter로 결과를 선택합니다. 검색창에서 경력 추가, 업로드, 이력서 만들기도 바로 실행합니다.
- 이력 검색 조건은 개별 해제할 수 있습니다. 목록의 **이력서로 만들기**를 누르면 현재 조건에 맞는 기록만 선택됩니다. 상세 화면에서는 한 줄 요약 복사와 해당 이력만 담기가 가능합니다.
- 공문 보관함에 파일 형식 필터, 최근 보관순, 이름순, 큰 파일순 정렬을 추가했습니다. 눈 모양 버튼으로 추출된 내용과 연결된 이력을 확인합니다. 미리보기에서 경력 연결, 초안 만들기, 원본 다운로드로 이어집니다.
- 홈과 검색 화면을 중립 회색, 흰색 카드, 민트 강조색으로 정리했습니다. 다크 모드에도 같은 구성과 대비를 적용했습니다.

## 범위와 데이터 보존

- 공문 살펴보기는 저장된 추출 텍스트를 보여 줍니다. 원본 PDF나 한글 문서의 지면 모양을 재현하지 않습니다. 텍스트가 없는 파일은 원본 다운로드를 안내합니다.
- 검색과 필터, 정리할 기록 집계는 읽기 전용입니다. 증빙 불필요 설정은 보완 대상에서 제외합니다. 실제로 남아 있는 파일을 기준으로 증빙 연결을 확인합니다.
- 네이버 캘린더 링크는 기존처럼 사이트 바로가기입니다. 양방향 동기화 기능은 포함되지 않습니다.
- 준비된 글로벌연수 암호화 자료 패키지는 그대로 유지합니다. 이번 화면 변경과 Git 푸시는 실제 계정의 자료 가져오기를 실행하지 않습니다.

## 검증

Node.js 24, 별도 임시 SQLite 데이터 폴더에서 검증합니다. 실제 Firebase와 드라이브에는 쓰지 않습니다.

```sh
npm run build
node --test test/archive-tools.test.mjs test/home-model.test.mjs
npx playwright test --grep-invert 'mobile|classroom materials|four workspaces contain'
```

마지막 명령은 모바일 검증이 섞여 있는 기존 테스트를 제외합니다. 새 테스트는 검색 순위와 키보드, 정리 대상, 즐겨찾기, 이력서 선택 전달, 공문 필터와 연결, 텍스트 안전 표시, 기존 데이터 보존을 검증합니다. 기존 데스크톱 이력 작성, 증빙, HWPX, JSON 복원, 테마, 연결과 동시 수정 테스트도 실행합니다.

실행 결과: 프로덕션 빌드 성공, 로직 테스트 6개 통과, 데스크톱 브라우저 테스트 14개 통과. 라이트, 다크 화면을 직접 확인했습니다. 기존 대형 JavaScript 청크에 대한 Vite 안내는 남아 있습니다.
