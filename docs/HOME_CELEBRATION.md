# 홈 첫 화면 축하 모션

2026-11-12 사용자 요청("메인 화면에 와, 뽕이 차는 모션")으로 홈의 "나의 성장" 지도에 짧은 축하 연출을 더했습니다. 저장 데이터와 API는 바꾸지 않았습니다.

## 흐름 (약 4초, 세션당 한 번)

1. 지도 카드 위쪽에 "20XX년부터 쌓아 온 나의 발자취" 제목과 실제 수치 카드(쌓아 온 이력, 활동한 해, 함께한 기관, 수상과 성과)가 떠오르며 숫자가 0부터 올라갑니다.
2. 성장 선이 왼쪽부터 그려지고 연도 점이 차례로 튀어 오르며, 각 연도의 기록 수도 함께 올라갑니다.
3. 가장 최근 연도에 도착하면 반짝이 파티클이 터지고 점이 두 번 맥동하며, 제목에 빛이 한 번 지나갑니다.
4. 지도 아래 "빛나는 순간"에 최근 수상·표창·연구대회 기록(최대 4개)이 날아들어 옵니다. 누르면 해당 이력이 열립니다.

## 규칙

- 같은 브라우저 탭 세션에서는 한 번만 재생합니다(`sessionStorage`의 `c-archive-home-intro-v1`). 오른쪽 위 ↻ 버튼으로 언제든 다시 봅니다.
- 아무 키나 누르거나 화면을 누르면 즉시 마지막 상태로 건너뜁니다. 탭을 숨기면 바로 끝납니다.
- 운영체제의 "동작 줄이기"를 켜면 모션과 파티클 없이 최종 화면만 보입니다.
- 모든 숫자와 수상 목록은 실제 이력에서만 계산합니다. 수상과 성과는 이력 분류가 표창, 공모전 수상, 연구대회인 기록입니다. 예정 이력과 연도 미입력 이력은 제외합니다.
- 레이아웃은 첫 프레임부터 최종 크기로 고정되고, 움직임은 transform/opacity와 캔버스만 씁니다.
