# 2026-11-13 스캔 증빙 추가

소유자가 보낸 스캔 PDF 16개, 총 17쪽을 이미지로 읽어 본인 이름, 발급기관, 날짜와 기존 이력을 대조했다. 본인 자료 15개를 반영하고 다른 사람 명의 심폐소생술 이수증 1개는 경력 등록에서 제외한다. 제외한 원본도 비공개 작업 폴더에 보존한다.

## 연결과 신규 기록

- 2020년 제28회, 2021년 제29회 교육방송연구대회의 대구 예선 1등급과 EBS 본대회 2등급은 같은 연도 기존 이력에 각각 연결한다. 단계와 수상일은 구분하며 연도별 경력을 중복 생성하지 않는다.
- 2022년 제30회 대구 예선 1등급, 2026년 제34회 대구 대회 1등급 상장도 해당 기존 이력에 연결한다. 증명되지 않은 전국 수상은 추가하지 않는다.
- 2022년, 2023년, 2024년 학교폭력 예방교육 컨설턴트 위촉장은 연도별 기존 이력에 연결한다. 별도 어울림 컨설팅 지원단, 어울림 서포터즈단, 어울림더하기 교사지원단과 구분한다.
- 함께 학교 교사지원단, AIEDAP 마스터교원, 2026년 어울림더하기 교사지원단 위촉장은 기존 이력에 연결한다.
- 새 기록은 2021년 남부교육지원청 교육장 표창 1건과 2018년 육상 입상 지도상 2건이다. 두 육상 지도상은 5월 학년별 우수선수 선발대회와 10월 정기대회의 서로 다른 상장이다. 개인 선수 순위나 등급은 추정하지 않는다.

PDF 제목을 날짜, 기관 또는 대회, 증빙 종류가 드러나게 바꾸고 원본 바이트는 그대로 둔다. 발급일과 위촉 시작일을 혼동하지 않는다. 2023년 컨설팅단의 교육청 위촉 기간은 3월 시작으로 유지하고, 교육부 위촉장의 5월 시작 기간을 별도 설명으로 보완한다.

## 저장과 검증

원문, 대조 내역, 가져오기 코드와 키는 `.cloud-local/scans-20261113` 및 `.cloud-local/scans-combined-20261113`에만 보관한다. Git에는 암호화된 자료와 검토 해시만 포함한다. 소유자가 비공개 가져오기 링크를 연 뒤 로그인과 저장소 연결이 되어 있으면 자동으로 연결한다. 자료 준비 또는 코드 푸시는 실제 계정에 저장된 상태를 뜻하지 않는다.
