# 연구대회 자료 보관함

연구대회(현장교육연구대회, 교육자료전 등)에 낸 계획서, 보고서, 발표자료, 부록과 증빙을 파일별로 보관하는 화면입니다. 맥에서 Codex로 만들다 만 작업(`wip/research-archive-mac`, `ca4fcd6`)을 2026-11-11에 현재 코드 기준으로 다시 구현했습니다. 사용자가 업그레이드 목록에서 직접 고른 기능입니다.

## 화면

- 사이드바: `사진 보관함`, `공모전 제출본` 바로 아래의 **연구대회 자료**. 공모전 제출본과 같은 "대회 관련 독립 보관함" 묶음이라 그 옆에 두었고, 이력이나 자료실 하위 메뉴에 넣지 않아 기존 목록 숫자가 바뀌지 않습니다.
- 목록은 **연도와 대회명으로 묶어** 최근 연도부터 보여 줍니다. 묶음 안에서는 계획서, 보고서, 발표자료, 부록과 증빙, 참고자료, 기타 순서입니다. 대회명과 연도가 없는 자료는 `대회와 연도 미입력` 묶음에 모입니다.
- 위쪽 종류 칩(전체, 계획서 등)과 검색어, 대회 선택, `즐겨찾기만`으로 거를 수 있습니다. 카드마다 즐겨찾기 별이 있고 홈의 즐겨찾기에도 나타납니다.
- 카드 아래에 원본 상태(`원본 보관됨`, `드라이브 링크`, `원본 확인 필요`, `원본 없음`)를 표시합니다.
- 통합 검색(Ctrl K)의 종류 선택에 `연구대회 자료`가 있고, 결과에는 `연구대회 자료 / 종류 / 연도 / 대회명 / 형식`이 보입니다.
- 자료 보관: 파일을 고르거나 끌어다 놓고, 제목과 종류를 정하면 저장됩니다. 대회명, 연도, 작성자, 메모, 태그, 관련 이력 연결은 선택입니다. 파일 대신 구글 드라이브 공유 링크만 저장할 수도 있습니다.

## 원본 저장 방식

원본은 사진 보관함과 같은 경로(`POST /documents`)로 **공문 보관함 원본**이 됩니다. 따라서 지금 쓰는 저장소(OneDrive 또는 구글 드라이브)를 그대로 따르고, 날짜별 백업, ZIP 백업, OneDrive 이전 대상에도 자동으로 포함됩니다. 자료 항목에는 원본의 `sourceFile`(이름, 크기, SHA-256)만 저장하고, 원본 받기는 같은 SHA-256과 크기를 가진 공문 기록을 찾아 내려받습니다.

연구대회 자료가 쓰는 원본은 공문 보관함에서 지울 수 없습니다(무료 모드 `deleteFreeDocument`, 로컬 서버 `DELETE /api/documents/:id` 모두 409). 연구대회 자료를 지워도 원본은 공문 보관함에 남습니다.

## 데이터 필드 (모두 추가형, 선택)

| 필드 | 값 | 설명 |
|---|---|---|
| `material.purpose` | `"research"` 추가 | 기존 `"lecture"`, `"classroom"`과 같은 자리. 없는 행은 지금처럼 자료실(강의 자료)입니다. |
| `material.researchType` | `계획서`, `보고서`, `발표자료`, `부록·증빙`, `참고자료`, `기타` | 없으면 화면에서 `기타`로 봅니다. 화면에는 가운뎃점을 쉼표로 바꿔 `부록, 증빙`으로 표시합니다. |

기존 행에는 필드를 추가하지 않습니다. 검증기 `shared/workspace.mjs`가 두 값을 허용하고 `RESEARCH_TYPES`를 내보냅니다. Firestore 행 인코딩, JSON 내보내기/가져오기, ZIP 백업과 복원, OneDrive/드라이브 날짜별 스냅샷은 학습 기록 전체를 그대로 다루므로 별도 변경이 필요 없고 테스트로 왕복을 확인했습니다. 로컬 서버의 공문 응답은 연구대회 원본을 찾을 수 있도록 `sha256`을 함께 돌려줍니다(본인 파일의 지문이며 저장 경로 `storageName`은 계속 숨깁니다).

자료실, 수업(학급 자료), 사이드바 자료실 숫자는 `purpose`가 없거나 `lecture`인 자료만 셉니다. 연구대회 자료는 섞이지 않습니다.

## 호환성 주의

넷리파이에 남아 있는 예전 버전(`363abb5`)은 `purpose: "research"`를 모르는 검증기를 써서, 연구대회 자료가 하나라도 생기면 학습 기록 전체를 읽지 못합니다. 다만 그 버전은 이미 OneDrive 파일 ID도 읽지 못하므로(OneDrive 전환 후 비상용으로도 쓸 수 없는 상태) 이번 변경으로 새로 생기는 제약은 아닙니다. Vercel 정식 버전만 사용합니다.

## 되돌리기

연구대회 자료를 저장한 뒤 화면만 되돌릴 때는 **검증기와 타입은 남겨야** 기존 자료를 계속 읽을 수 있습니다. 먼저 전체 백업 ZIP을 받아 둔 뒤:

```sh
git revert --no-commit <연구대회 자료 커밋>
git restore --source=<연구대회 자료 커밋> -- shared/workspace.mjs shared/workspace.d.mts src/workspace/types.ts
git commit -m "Hide research archive view while keeping stored research materials readable"
```

화면을 되돌리면 연구대회 자료는 자료실 목록에서 보이지 않지만 데이터와 원본은 그대로 남고, 다시 적용하면 돌아옵니다.
