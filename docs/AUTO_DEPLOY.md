2. 소스만 저장할 때는 커밋에 `[skip netlify] [skip ci]`를 붙입니다. 병합 커밋에도 같은 원칙을 적용합니다.

5. 승인된 최종 배포 커밋에는 skip 표시를 넣지 않습니다. Netlify의 기존 GitHub 연결을 사용하며 별도 Actions나 build hook을 중복 호출하지 않습니다.
