# 기록실 화면 정리

2026-10-26 요청에 따라 기존 앱을 정리했다. 작업 전 코드는
`backup/before-clean-ui-20261026` (`f0ac5fa`)에 보관한다.

- 홈: 이력 요약 수치와 성장 지도, 검색, 즐겨찾기, 백업.
- 왼쪽 메뉴: 홈, 이력, 수업, 강의 자료, 사진 보관함, 공모전 제출본.
- 최근 작업, 최근 활동, 일정과 마감, 대학원 화면과 사용자 이니셜 제거.
- 자료: 작은 목록 기본 보기, 업로드 날짜순 정렬, 과목과 태그 검색.
- 태그: 제목, 추출된 내용, 파일명에서 과목과 활동을 추론한다. 유료 AI 호출은 없다.
  기존 태그가 우선이며 저장 제한 안에서만 제안 태그를 추가한다.
- 아이콘: 평면 선 아이콘과 기록책 북마크 아이콘. 본문 16px, 컨트롤 14px,
  보조 정보 12px를 기준으로 기존 Pretendard와 Paperlogy를 유지한다.

저장 형식과 API는 변경하지 않았다. 숨긴 대학원 기록, 기존 제작자와 날짜,
대상 정보, 연결 관계는 삭제하지 않으며 전체 JSON 백업에도 보존한다.
기존 자료의 자동 태그는 화면에서 먼저 계산하고, 사용자가 저장할 때 반영한다.
업로드 날짜는 `createdAt`을 서울 시간으로 표시한다. 수정일이나 활동일을 대신 쓰지 않는다.

아이콘 원본은 이미지 생성 도구로 제작했고 공개 자산에는 축소한 PNG만 포함한다.
개인 원본 파일과 테스트 백업은 저장소에 추가하지 않는다.

## 되돌리기

코드만 확인하려면 `git switch backup/before-clean-ui-20261026`.
운영 화면 복구가 필요하면 이 변경의 릴리스 커밋을 `git revert`하고
복구 커밋을 한 번 배포한다. 데이터 복원이나 Firebase, Drive 변경은 필요 없다.
브랜치의 과거 상태로 main을 강제 푸시하지 않는다.

이번 요청은 최종본 자동 배포를 명시적으로 포함한다. 로컬 검증을 마친 코드를
기존 GitHub 연결로 main에 한 번만 푸시한다. 이후 일반 작업은 미리보기 우선이다.
Netlify 게시 확인이 차단되면 푸시 성공과 Published 확인을 구분해서 보고한다.
