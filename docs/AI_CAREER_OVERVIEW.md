# 공문 AI 분석과 이력 한눈에 보기

2026-10-26, 기존 앱에 추가. 저장된 이력, 증빙, 관계, JSON/ZIP 백업 형식은 변경하지 않는다. 데이터 마이그레이션은 필요 없다.

## Gemini 연결

1. 앱에서 본인 계정으로 로그인하고 **백업 및 설정 → 공문 AI 분석**을 연다.
2. **Google AI Studio에서 키 발급** 링크(https://aistudio.google.com/apikey)에서 API 키를 발급받는다.
3. 앱의 비밀번호 입력란에 붙여 넣고 **연결 확인 후 저장**을 누른다. 키를 채팅이나 Git에 올리지 않는다.
4. 실제 Gemini 응답이 확인되면 **Gemini 연결됨**이 표시된다. 이후 공문 분석에 사용된다. 이전 공문은 공문 보관함에서 **분석**으로 다시 처리한다.

Netlify 환경 변수 변경이나 재배포는 필요 없다. 기본 모델 설정은 **자동 선택**이다. 키 발급과 실제 인증은 소유자가 한 번 완료해야 한다. 이 변경을 개발한 환경에는 Gemini 키가 없으므로 실제 계정의 연결 완료를 뜻하지 않는다.

모델 연결 보정: 기본 모델을 특정 이름에 고정하지 않고, 같은 키로 Google의 `v1beta/models` 목록을 조회한다. 텍스트 생성을 지원하는 일반 Flash 모델 중 안정 버전과 최신 세대를 우선하며, 같은 세대에서는 Flash Lite를 먼저 확인한다. 이미지 생성/음성/임베딩 전용 모델과 Pro 모델은 자동 선택에서 제외한다. 자동 선택은 무료 사용을 보장하는 기능이 아니며, 실제 한도와 과금은 Google 프로젝트 설정을 따른다.

목록에 나온 모델에 합성 JSON 응답을 요청해 분석용 응답을 확인한 뒤 실제 모델 이름과 키를 암호화 저장한다. 목록은 최대 5페이지, 모델 검사는 최대 3개, 네트워크 작업은 총 18초 이내로 제한한다. 목록에 나온 모델이 404/410을 반환하면 다음 후보를 확인하지만, 키 권한/사용 한도 오류에서는 추가 모델 호출을 하지 않는다. 실패하면 기존 키와 연결을 유지한다. 직접 지정은 **모델 설정 → 모델 직접 지정**에서만 사용하며 이 경우 다른 모델로 대체하지 않는다. 기존에 저장된 모델은 자동으로 변경하지 않는다. 새로 연결할 때는 **자동 선택**이 기본값이다. 모델 보정 전 코드는 `backup/before-gemini-model-discovery-20261026` (`0f8f66b`)이다.

키 입력 보정: 입력칸의 200자 자동 잘림과 서버의 영문/숫자/밑줄/하이픈 전용 검사를 제거했다. 키 접두어와 형식을 추정하지 않고 Google의 실제 응답을 확인한 뒤에만 저장한다. 바깥 공백과 한 쌍의 따옴표는 정리하지만 내부 문자열은 보존한다. 가려진 값, 내부 공백, 제어 문자, 4096자를 넘는 입력은 값을 노출하지 않는 안내로 거절하며, 긴 입력을 몰래 자르지 않는다. 실제 사용자의 키나 클립보드는 확인하지 않았으므로 기존 오류 원인은 확정되지 않았다. 이 보정 전 코드는 `backup/before-ai-key-fix-20261026` (`0211802`)이다.

키 검사는 합성 문장만 전송한다. 실제 분석 시 문서 본문, 또는 읽을 수 있는 텍스트가 없는 10MiB 이하 PDF/JPEG/PNG/WEBP 원본을 Google Gemini로 보낸다. HWP 등 변환이 필요한 형식은 변환 안내와 기본 초안을 제공한다. 무료 한도와 과금은 연결한 Google 프로젝트 설정에 따른다. 이 기능은 결제나 사용 한도를 변경하지 않는다.

소유자 인증과 동일 출처 확인 뒤 서버가 키를 검증한다. 성공한 키만 기존 Netlify 비공개 암호화 vault에 저장한다. Firestore, JSON/ZIP/Drive 기록 백업, 상태 응답, 브라우저 저장소에는 키를 넣지 않는다. 키 교체 실패 시 기존 연결을 유지한다. 연결 해제는 저장된 키를 제거하고 서버 환경 변수에 있는 키 사용도 중단한다. 이력과 원본은 그대로 둔다.

Gemini 사용 한도, 모델 오류, 읽을 수 없는 파일, 미연결 상태를 구분해서 안내한다. 분석에 실패해도 원본과 확인 가능한 기본 초안을 유지한다. AI가 제안한 이력은 검토 전 상태로 열리며 사용자가 저장해야 기록에 반영된다. 여러 초안은 **남은 초안 N개**로 표시한다.

## 전체 이력표

홈의 **이력 한눈에 보기** 또는 이력 화면의 **한눈에 보기**에서 연도와 분야별 현황, 전체 이력표를 연다. 표는 페이지를 나누지 않고 기관, 역할, 등급/단계, 증빙 수까지 보여 준다. 연도, 분야, 교차 셀을 누르면 해당 이력만 표시한다. **전체 펼치기**로 해제한다.

검색은 이력명, 기관, 역할, 태그, 연도, 수상 등급과 단계를 포함한다. 기간이 여러 해여도 시작 연도로 한 번만 집계하고, 연도가 없는 이력도 별도로 포함한다. 제목을 누르면 기존 상세 화면을 연다. 인쇄는 현재 표시된 이력표를 출력한다.

## 검증과 배포

실제 Firebase/Drive 데이터 대신 합성 데이터와 격리된 저장소로 검사한다. AI 키 저장/해제, 실패 시 기존 키 보존, 소유자/출처 제한, 스캔 PDF 요청, AI 결과 정규화, 기존 백업 복원과 이력 CRUD를 포함한다. 브라우저에서는 전체 이력 수, 검색/필터/상세/인쇄, 밝은/어두운 테마를 점검한다. 실제 Gemini 호출은 소유자의 키 등록 후 검사되므로 개발 테스트는 Gemini 응답을 대체한다.

배포는 검증을 마친 한 커밋을 `main`에 한 번 푸시해 기존 GitHub-Netlify 연결을 사용한다. 원격 커밋 일치와 Netlify `Published` 확인은 별개다. 접근 제한으로 공개 상태를 확인하지 못하면 그 사실을 명시한다.

## 되돌리기

변경 전 코드는 `backup/before-ai-overview-20261026` (`d4b924b`)에 보존했다. 최종 기능 커밋을 `git revert`하고 일반 절차로 배포하면 된다. 강제 푸시는 필요 없다. Gemini 연결을 끄려면 앱에서 먼저 **연결 해제**를 누른다. 코드 되돌리기 자체는 기록이나 서버 vault를 삭제하지 않는다.
