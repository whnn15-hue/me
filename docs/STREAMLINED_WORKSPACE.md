# 파일 등록과 작업 공간 업데이트

이 문서는 이전 업데이트 기록입니다. 현재 메뉴 계층과 중복 없는 이력 분류는 [이력 분류와 기관별 보기](CAREER_COLLECTIONS.md)를 참고하세요.

파일을 공문 보관함, 이력, 수업 또는 강의 자료 화면에 끌어 넣습니다. 공문은 기존처럼 이력 초안을 확인한 뒤 저장합니다. 수업과 강의 자료 파일은 연결한 개인 Drive에 원본을 보관하고 제목, 형식, 과목, 기초훈련, 태그, 활용 메모를 채운 자료 카드로 등록합니다. 작성자와 날짜는 원문에 명시된 값만 사용합니다.

자동 정리는 파일명과 읽을 수 있는 본문의 규칙을 사용하며 별도 유료 AI 설정이 필요하지 않습니다. PDF, HWP, HWPX, TXT, DOCX, PPTX의 텍스트를 이용합니다. 보호된 한글 파일, 스캔 PDF, 이미지, 구형 PPT처럼 본문을 읽지 못한 파일도 원본을 보관하고 파일명으로 분류합니다. 최대 10개, 파일당 25 MB입니다. 같은 자료를 같은 보관함에 다시 넣으면 기존 수정 사항과 링크를 유지합니다.

수업 자료에는 과목과 기초훈련 분류를 사용합니다. 직접 제작 또는 수집 구분은 화면에서 제거하되 기존 저장 값은 보존합니다. 예전 자료도 제목과 메모, 태그로 분류해 표시하므로 데이터를 다시 가져올 필요가 없습니다. 직접 등록할 때는 제목과 링크, 분류만 먼저 보이고 나머지는 추가 정보에서 엽니다. 수업 기록의 상세 항목도 접어서 표시합니다.

파견, 집필, 콘텐츠 제작은 각각의 탭에서 찾습니다. 기존 분류와 제목, 역할, 태그, 내용으로 관련 기록을 모으며 파견은 연결된 공문의 파일명도 참조합니다. 같은 활동이 집필과 촬영을 포함하면 두 탭에 같은 ID로 표시합니다. 이력과 공문을 복사하거나 재작성하지 않습니다.

연구와 수상은 대회 범위, 등급, 예선과 본선 등 단계를 배지로 표시합니다. 원래 내용에서 읽을 수 있는 값을 표시하며 수정 화면에서 직접 지정할 수도 있습니다. 시도와 전국에 각각 등급이 있으면 범위와 등급의 짝을 함께 표시합니다. 값이 없으면 등급 미기재로 표시합니다.

설명과 홍보 문구를 덜어내고 목록의 제목과 기관, 날짜, 증빙을 읽기 쉽게 정리했습니다. Paperlogy는 제목과 메뉴 등 강조 영역에만 사용하며 본문은 기존 글꼴을 사용합니다. 업로드된 Medium, SemiBold, Bold를 WOFF2로 압축해 전체 글리프를 보존하고 폰트 저작권과 OFL 1.1을 함께 배포합니다.

## 데이터와 호환성

기존 항목에는 필드를 일괄 추가하거나 분류를 덮어쓰지 않습니다. 이전의 복합 분류도 계속 읽습니다. 새 자료에는 선택 필드 `subjects`, `trainings`, `sourceFile`을 사용할 수 있고 연구 수상에는 `awardLevel`, `awardGrade`, `awardStages`를 사용할 수 있습니다. 기존 스키마 버전과 ID, 연결, 저장 경로는 그대로 유지합니다. 추가 필드는 JSON과 ZIP, Drive 메타데이터 백업에 함께 보존됩니다. 자료 원본은 Drive에 별도로 유지하는 기존 방식을 따릅니다.

자동 등록은 현재 서버 버전을 확인하고 새 자료와 목록 개수만 한 번에 저장합니다. 기존 이력과 공문 전체를 다시 쓰지 않습니다. 다른 기기에서 바뀐 내용과 충돌하면 현재 데이터를 유지하고 새 업로드만 정리합니다. 저장 응답이 불확실한 경우 이미 연결됐을 수 있는 원본은 삭제하지 않습니다.
